# 需求定版

2026-11-24 与用户逐项确认后定版，开工依据。之后改需求先改这份文档。

1. **技术**：WebView2 原生壳（.NET 6），包 muse.ai；应用名 Muse for Windows；图标为柠檬图。
2. **常驻**：全常驻——开机自启、关窗不退出缩回托盘、托盘右键才能真退出。
3. **自启方式**：静默起到托盘，不弹窗口打扰用户。
4. **呼出**：全局快捷键默认 Ctrl+Alt+N，按一下出、再按一下收；托盘里可改，改完立即生效。（原定 Ctrl+Alt+M，2026-11-24 在目标机实测已被其他程序占用——RegisterHotKey 返回错误 1409，故改用 N。壳在注册失败时会弹托盘提示并写 hotkey.log，不再静默失效。）
5. **登录**：壳独立数据目录，第一次在壳里登录一次，之后持久保持。
6. **链接**：站内跳转留在壳里，外站链接（新窗口打开的）用默认浏览器打开。
7. **窗口习惯**：记住上次的大小和位置；单实例，重复启动只呼出已有窗口。
8. **项目管理**：源码按项目放 GitHub 公开仓库 `Jayon28/muse-windows-shell`，结构清晰易读；编译产物、登录数据、密钥一律不进仓库；每次改完 commit 并写清改了什么。
9. **缩放记忆**：页面缩放（Ctrl +/-）持久化保存，退出重开恢复。
10. **运行时检测**：首次启动弹带进度条的检测窗查 .NET 与 WebView2，通过后不再检测；托盘右键有「重新检测运行时」；缺组件引导去微软官网下载。发行包不打包 .NET（框架依赖发布）；运行时不挂 Release：官方安装包放在仓库根目录 Redist\ 文件夹（Git LFS 托管）供直接下载，也可去微软官网下载；install.ps1 检测到缺失时会先用 Redist 里的自动补装。
11. **多语言**：界面文字集中在 Program.cs 的 Strings 表（zh/en 两套）；默认跟随系统界面语言（中文→中文、其他→英文兜底），托盘菜单「语言 / Language」可手动切换（跟随系统 / 简体中文 / English），立即生效并存入 settings.json 的 Language 字段。要加新语言只需在 Strings 里补一套字典。
