Muse for Windows（免安装版）

用法：
1. 把整个文件夹解压到任意位置，双击 Muse.exe 运行。
2. 第一次打开，用你自己的 Muse 账号在窗口里登录一次，之后自动保持登录。
3. 关窗口 = 缩到托盘，不退出；托盘右键菜单可以退出、改快捷键。
4. 全局快捷键默认 Ctrl+Alt+N：按一下呼出窗口，再按一下收起。
   若提示注册失败，是被其他程序占用了，在托盘菜单「设置快捷键…」里换一个。
5. 界面语言默认跟随系统（中文系统显示中文，其他系统显示英文）；托盘菜单「语言 / Language」里可以手动切换。
6. 不想用了：托盘右键退出，然后直接删掉这个文件夹即可。
   登录数据在 %LOCALAPPDATA%\MuseShell，要全清把它一起删掉。

前置条件（缺了打不开）：
- .NET 6 桌面运行时：可从 GitHub 仓库根目录的 Redist 文件夹下载，也可从微软官网下载
  https://dotnet.microsoft.com/download/dotnet/6.0
- WebView2 运行时：Win11 自带；没有的话第一次启动的检测窗会引导下载，
  也可以从 GitHub 仓库根目录的 Redist 文件夹下载，或从微软官网下载
  https://developer.microsoft.com/microsoft-edge/webview2/
第一次启动会先弹一个检测窗确认这两样都在，通过后就不再出现；
托盘右键菜单里有「重新检测运行时」可以手动再检一次。
页面缩放（Ctrl +/-）会记住，退出重开不丢失。

说明：这是把 muse.ai 包进原生窗口的非官方小壳，需要 Windows 10/11。

Muse for Windows (portable build) — English

How to use:
1. Extract the whole folder anywhere and run Muse.exe.
2. On first launch, sign in with your own Muse account in the window; it stays signed in afterwards.
3. Closing the window only hides it to the system tray — it does not quit. Use the tray menu to quit or change the hotkey.
4. The global hotkey defaults to Ctrl+Alt+N: press once to summon the window, press again to hide it.
   If registration fails, another app is using that combo — pick a different one in the tray menu ("Set hotkey…").
5. The UI language follows your system by default (Chinese on Chinese systems, English elsewhere); switch it manually in the tray menu under "语言 / Language".
6. To remove it: quit from the tray menu, then just delete the folder.
   Sign-in data lives in %LOCALAPPDATA%\MuseShell — delete that too for a full wipe.

Prerequisites (the app won't start without them):
- .NET 6 Desktop Runtime: download it from the Redist folder at the root of the GitHub repo, or from Microsoft:
  https://dotnet.microsoft.com/download/dotnet/6.0
- WebView2 Runtime: built into Windows 11; if missing, the first-launch check window will guide you,
  or download it from the Redist folder at the root of the GitHub repo, or from Microsoft:
  https://developer.microsoft.com/microsoft-edge/webview2/
On first launch a check window confirms both are present; once passed it never shows again.
The tray menu has "Re-check runtimes" if you ever want to run it manually.
Page zoom (Ctrl +/-) is remembered across restarts.

Note: this is an unofficial shell that wraps muse.ai in a native window. Requires Windows 10/11.
